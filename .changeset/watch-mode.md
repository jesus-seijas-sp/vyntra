Watch mode: `vyntra --watch` (or `vyntra watch`, or `--watchAll`) runs the tests, then what each change touches: a changed test file, the test files that loaded a changed module, a new test file, or everything when the config changes. In a terminal, Enter reruns, `a` runs all, `f` the failures, `p` and `t` filter by file and by test name, `q` quits.
