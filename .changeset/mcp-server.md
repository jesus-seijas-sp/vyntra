The first release of `@vyntra/mcp`, an MCP server (`npx vyntra-mcp`) for coding agents: `run_tests`, `list_failures`, `read_failure` (with the screenshot of an end-to-end failure), `guide`, and `try_locator` to try a Playwright locator on a page. It speaks the stateless 2026-07-28 revision and the `initialize` handshake of earlier ones.
